매뉴얼

유튜브 영상에서 원하는 구간만 잘라 순서대로 이어 보는 도구입니다. 영상 파일을 자르거나 새로 만드는 것이 아니라, [영상 주소 + 시작 시간 + 종료 시간] 목록을 만들어 유튜브 플레이어에 차례대로 재생시키는 방식입니다. 원본 영상은 전혀 건드리지 않습니다.

1전체 구조

  • 화면은 보기 모드와 편집 모드 두 가지로 구성됩니다. 우측 상단에서 전환합니다.
  • 편집 모드 — 좌측은 미리보기 플레이어, 우측은 구간을 추가·수정하는 편집창입니다.
  • 보기 모드 — 좌측은 플레이어, 우측은 완성된 재생 목록입니다. 편집한 내용이 즉시 반영됩니다.
  • 작업 결과물은 JSON 한 덩어리입니다. 이 JSON을 파일 저장·불러오기·링크 공유에 그대로 사용합니다.
  • 구간 종료 시간에 닿으면 다음 구간으로 자동 진행됩니다. 마지막 구간까지 가면 멈춥니다.
  • 보기 모드로 들어가면 재생 목록의 첫 구간 시작 지점 화면이 정지 상태로 미리 떠 있습니다. 재생 버튼을 누르면 그 지점부터 이어집니다.
  • 플레이어 아래 컨트롤은 이전 구간 · 현재 구간 다시 · 다음 구간 · 정지이고, 오른쪽 검은 버튼 은 첫 구간부터 전체 재생입니다. 정지를 누르면 첫 구간 시작 지점으로 되돌아갑니다.

2보관 방식 — 먼저 알아둘 것

  • 로그인이 필요 없습니다. 링크만 있으면 누구나 열어서 보고, 고치고, 파일로 내려받을 수 있습니다.
  • 보관 방법은 두 가지임 — .json 파일로 내려받기, 공유 링크 만들기.
  • 자동 저장은 없습니다. 저장하지 않고 창을 닫거나 새로고침하면 작업 내용이 사라집니다.
  • 공유 링크를 연 사람이 내용을 고쳐도 원본 링크에는 반영되지 않습니다. 고친 내용은 따로 저장해야 남습니다.
  • 크롬 확장 프로그램 유튜브 구간 편집을 쓰면 작업 내용이 자동 저장되고, 구입·대여한 영상도 재생할 수 있습니다. 이 페이지는 그 확장이 만든 링크를 열어 보는 용도이기도 합니다.

3편집 모드 사용법

  • 우측 하단 ＋ 구간 추가로 구간을 원하는 만큼 늘립니다. 개수 제한은 없습니다.
  • 한 구간은 [URL · 시작 · 종료] 한 쌍으로 이루어집니다. 구간 이름은 선택 사항입니다.
  • 카드 우측 버튼 — 순서 이동, 이 구간부터 이어서 재생, 삭제입니다.
  • 시간칸 옆 ⤓ 는 미리보기에서 지금 재생 중인 위치를 그 칸에 담는 버튼입니다. 영상을 보다가 원하는 지점에서 누르면 됩니다.
  • 상단 제목칸을 클릭해 페이지 제목을 바꿀 수 있습니다. 제목은 JSON에 함께 저장됩니다.
  • 구간 목록 제목 옆에 전체 재생 길이와 구간 개수가 표시됩니다. 종료 시간을 비워 둔 구간은 길이를 알 수 없어 합계에서 빠지며, 이때 숫자 뒤에 + 가 붙습니다.
  • 초기화는 제목과 모든 구간을 지웁니다. 되돌릴 수 없으므로 확인 창이 한 번 뜹니다.

4URL 입력 규칙

  • 인식되는 형식 — https://youtu.be/ID, youtube.com/watch?v=ID, youtube.com/shorts/ID, embed/ID, live/ID, 11자리 ID 자체입니다.
  • URL 칸을 비우면 바로 위 구간의 영상을 그대로 이어받습니다. 한 영상에서 여러 구간을 뽑을 때 첫 구간에만 URL을 넣으면 됩니다.
  • 이어받는 중인 구간은 카드 아래에 어떤 영상을 물려받았는지 표시됩니다.
  • 첫 구간의 URL이 비어 있으면 이어받을 대상이 없으므로 경고가 표시됩니다.

5시간 입력 규칙

  • 입력 가능한 형태 — 00:00(분:초), 0:00:00(시:분:초), 288(초 단위 숫자) 모두 가능합니다.
  • 칸에서 커서가 빠지면 00:00 형식으로 자동 정리됩니다. 90 → 01:30.
  • 시간칸에 ?t=288 이 붙은 유튜브 링크를 그대로 붙여넣으면 시간만 뽑아 04:48 로 변환합니다. URL 칸이 비어 있고 다른 영상이면 URL 칸도 함께 채워집니다.
  • URL 칸에 ?t= 가 포함된 링크를 넣었는데 시작 시간이 비어 있으면, 그 값을 시작 시간으로 자동 입력합니다.
  • 종료를 비우면 영상 끝까지 재생합니다. 종료가 시작보다 앞서면 종료를 무시합니다.

8공유 링크

  • 우측 상단 공유 버튼을 누르면 링크가 바로 만들어집니다. 따로 저장할 필요가 없습니다. 복사해서 그대로 전달하면 되고, 받는 사람은 로그인 없이 열 수 있습니다.
  • 링크 안에 재생목록 데이터가 통째로 들어 있어, 파일을 저장하지 않아도 공유됩니다.
  • 데이터는 주소의 # 뒤에 담깁니다. 서버로 전송되지 않아 기록에 남지 않고, 길이 제한도 사실상 없습니다.
  • 링크를 연 사람은 보기 모드로 시작하며, 편집 모드로 전환해 수정할 수도 있습니다. 단, 그 수정은 원본 링크에 반영되지 않습니다. 별도로 저장해야 합니다.
  • 링크를 열면 첫 구간의 시작 지점 화면이 정지 상태로 뜹니다. 재생은 받는 사람이 직접 눌러야 시작됩니다.

9문제가 생겼을 때

영상이 안 나옴
저작권자가 외부 재생(임베드)을 막아둔 영상이거나, 유튜브에서 구입·대여한 영상입니다. 플레이어 위 유튜브에서 열기로 확인하고, 다음 구간으로 넘기면 됩니다. 구입한 영상까지 이어 보려면 크롬 확장 프로그램을 쓰세요.
구간이 안 넘어감
종료 시간이 비었거나 시작보다 앞서 있는지 확인해 주세요. 종료가 비면 영상 끝까지 재생합니다.
목록이 비어 보임
URL이 없거나 형식이 잘못된 구간은 재생 목록에서 제외됩니다. 편집 모드의 경고 문구를 확인해 주세요.
작업 내용이 사라짐
자동 저장이 없어서 새로고침하면 초기화됩니다. 작업 중간중간 .json 다운로드나 공유 링크 복사로 남겨 두세요.
